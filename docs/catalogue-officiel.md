# Contenus du site officiel Beyond Expertise

Vérification du 11 septembre 2026, sur le domaine confirmé par l’utilisateur : **https://beyond-expertise.com**.

## Résultats

Les liens du [catalogue officiel](https://beyond-expertise.com/formations) conduisent à **81 fiches uniques**, toutes récupérées avec une réponse HTTP 200. Chaque fiche contient un titre, une présentation, des objectifs, un public, des prérequis, une durée, un niveau et une modalité. Tarifs et sessions sont également affichés ; leur réalité commerciale n’a pas été confirmée.

**Les 81 fiches affichent les mêmes quatre rubriques génériques à la place d’un programme détaillé propre à chaque formation.** L’inspection du code confirme que le composant écrivait ces rubriques directement dans la page, indépendamment du parcours choisi. La [fiche Python pour Data Analyst](https://beyond-expertise.com/formations/python-pour-data-analyst) illustre ce défaut.

**Aucun lien direct vers un PDF, notebook, CSV, ZIP ou MP4 n’a été trouvé dans le contenu principal des 81 fiches.** Le bouton pour recevoir le programme conduit à une demande de devis. Cela ne démontre pas l’absence de supports privés ailleurs.

Les pages [apprenant](https://beyond-expertise.com/apprenant) et [formateur](https://beyond-expertise.com/formateur) décrivent des accès LMS à configurer. Aucun cours intégral n’a été identifié par ces accès publics. Aucun compte privé du site officiel n’a été utilisé.

La page [ressources](https://beyond-expertise.com/ressources) propose cinq entrées éditoriales : Copilot, agents IA, sécurité IA, Lakehouse et LLMOps. Elle ne constitue pas une bibliothèque de leçons consultables.

## Contenu repris dans le nouveau projet local

Le catalogue contient les 81 fiches avec leurs objectifs, publics, prérequis, durées, niveaux, modalités, URL source et date d’observation. Les quatre rubriques génériques sont retirées. Les prix sont présentés comme des montants observés sur le site officiel. Aucune session commerciale ni inscription réelle n’a été copiée.

Un module pilote est rattaché à Python pour Data Analyst : six leçons développées, un atelier guidé de 26 cellules, un TP de synthèse et un quiz de dix questions avec feedback explicatif. Ce module d’environ deux heures couvre une partie du parcours de trois jours présenté au catalogue.

Les 80 autres fiches indiquent que leur cours e-learning est à préparer. Le reste du parcours Python de trois jours est également à produire. **81 fiches ne signifient pas 81 formations en ligne terminées.**

Deux jeux synthétiques distincts sont utilisés : fournitures pour l’atelier, matériel informatique pour le TP. Les indices et corrections des micro-exercices sont repliables. Les essais de l’atelier s’exportent ; le TP possède un brouillon synchronisé et une remise persistante. Son corrigé est réservé jusqu’au retour du formateur.

## Limites et suite

Le commit exact déployé, un éventuel LMS privé et les supports hors ligne des formateurs restent non vérifiés. Ces ressources permettraient de reprendre d’autres cours existants qui ne sont pas exposés publiquement.

Le site officiel affiche une certification acquise, alors que la consigne de l’utilisateur indique une démarche en cours. La nouvelle version conserve cette dernière formulation. Les chiffres commerciaux du site officiel ne sont pas considérés comme des preuves vérifiées.

Pour terminer le produit : valider le module avec des apprenants, mesurer sa durée, compléter le parcours Python puis produire les cours des autres fiches avec leurs propres programmes, activités, évaluations et supports autorisés. L’hébergement reste une étape ultérieure. Aucun calendrier ni coût supplémentaire n’est engagé.
